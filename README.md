# 文冬三天两夜 · 家庭游行程

2026 年 8 月 29–31 日（周六至周一国庆日）文冬（Bentong, Pahang）家庭旅游行程网页。
一家七口（4 大人 + 3 小孩），住 27 Ah Peng — Bentong At Your Doorstep。

## 内容

- **住宿资讯** — Agoda 订单资料、地图导航、一键致电
- **三日行程** — 已排定的时间轴，含车程、门票、营业时间，每天附备案
- **美食与手信** — 老街必吃、文冬姜、豆腐卜、应季榴莲
- **实用资讯** — 开车过路费、天气穿着、现金网络、带小孩安全、紧急联络
- **备选方案** — 每天附「今天的备案」，天气不好可整块换
- **打包清单** — 可勾选，进度存在浏览器 localStorage
- **预算估算** — 7 人不含住宿的花费区间

## 使用

已上线：<https://q44travel.web.app>

也可以直接用浏览器打开 `index.html`，不必架伺服器。
页面分成 **住宿 / 三日行程 / 景点 / 吃什么 / 备忘** 五个分页，
手机、平板、桌面都做了响应式排版，并支援浅色 / 深色主题。

## 行程怎么排的

三天已经排定，写死在 `index.html` 里，不需要投票也不连资料库。排的原则：

- **一天只放一个大行程** —— 七个人里三个小孩两位长辈，上午出城下午再进山会走不动
- 第一天锁在**周六夜市**（一周只开这一晚，刚好是入住当天）
- 第二天是唯一装得下大行程的一天，给了**文冬休闲农场**（需提前 24 小时买票）
- 第三天国庆日，**2 点半前必须上高速**，所以只排手信和一站室内的

营业时间已经对过：开记 11:00 收摊排第一天早上；溏记和陈雪糕周一休，所以不排在第三天。
每天下面都有「今天的备案」，天气不好或临时改主意可以整块换。
